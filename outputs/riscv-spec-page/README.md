\# RISC-V Spec 汇总页任务输出



本目录用于存放 RuyiSDK 官网 RISC-V Spec 汇总页任务的阶段性输出。



\## 当前包含

\- `spec-overview.md`：页面导读文案

\- `spec-cards.json`：Spec 卡片数据初稿

\- `implementation-notes.md`：网页实现说明

\- `screenshots/`：本地网页原型截图

\- `web-prototype/`：本地 `ruyisdk-website` 原型中实际修改的页面代码文件
